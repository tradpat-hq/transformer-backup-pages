Private utility · Google Drive · rclone

Encrypted backups, under the owner's control.

Transformer Backup is a personal, non-commercial backup workflow. It uses the official rclone application and Google Drive authorization to store and retrieve owner-managed encrypted backup files.

What this utility does

  • Prepares encrypted backup files locally before uploading them to the owner's Google Drive.
  • Uses Google Drive access only for owner-directed operations such as listing, uploading, downloading, checking and managing backups.
  • Keeps the private decryption identity separate from uploaded backup files.
  • Supports verifying downloaded encrypted backups before any separately authorized recovery.

About this website

This is a static informational website for the owner's Google OAuth client. It does not sign users in, process backups, collect Google OAuth tokens or provide an online file-management interface. Backup operations take place through rclone on the owner's computer.

Transformer Backup is not a public backup service and does not offer account registration or subscriptions.

Google Drive permissions

The owner may authorize the full Google Drive scope so rclone can work with existing backup folders and verify stored files. This scope is broad: an authorized rclone client could read, create, modify and delete files. Actual operations are initiated by the owner under their own controls; this public website does not use those permissions.

Privacy and contact

For details about data handling, permissions, retention and revoking access, please read the Privacy Policy.

For questions about these public pages, use the repository issue tracker. Do not submit private files, access tokens or recovery keys.
