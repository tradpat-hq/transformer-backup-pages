Privacy Policy

Last updated: October 17, 2026

Transformer Backup is a privately operated, non-commercial workflow for the owner's encrypted backups. This policy describes the intended use of Google Drive access through rclone and the limited role of this public website.

1. Information accessed

When the owner authorizes rclone with Google OAuth, rclone may access the Google Drive metadata and files necessary for owner-directed backup and recovery operations. The selected OAuth scope may be the full Google Drive scope, which permits broad access to the owner's Drive files; it is not restricted by the address of this website or merely by choosing a backup folder.

This website itself does not request Google sign-in, receive OAuth authorization codes or tokens, upload personal documents or read Google Drive contents.

2. How information is used

Google Drive access is used for operations initiated by the owner, including locating existing backup folders, uploading locally encrypted archives, checking file metadata, downloading encrypted backups, verifying integrity and managing retained backup objects. Files are not accessed for advertising, profiling or resale.

For the backup workflow, selected file contents are encrypted locally before upload. Decryption identities are intended to remain under the owner's separate control and are not part of the Drive backup payload.

3. Storage and sharing

Encrypted backup objects are stored in the owner's selected Google Drive account and remain there until the owner chooses to remove them. OAuth credentials are managed locally by rclone under the computer user's permissions, not by this static website. The site has no application database or remote token storage.

Transformer Backup does not operate a third-party data brokerage service or intentionally transfer Google Drive user data to advertisers. Google Drive processes stored files under Google's own service terms and privacy practices. GitHub hosts these public pages and may process ordinary website access information under its own privacy statement.

4. Security and limits

Access should use the owner's Google account and official OAuth flow. Sensitive archives should be encrypted before upload, recovery keys stored separately, and file integrity verified before recovery. No system is guaranteed free of risk. The chosen Google Drive permission is broad, so local rclone configuration and computer account access must be protected.

This is not a system-image or automatic full-device backup service; the precise selection and recovery coverage depend on each backup operation.

5. Control, deletion and revocation

The owner controls which local files are selected and when backup files are uploaded, retrieved or deleted. The owner can remove backup objects from Google Drive and revoke the OAuth authorization from Google Account → Third-party connections. Removing OAuth access stops further authorized API operations but does not itself delete files already stored in Drive.

6. Questions and policy updates

For questions about the privacy information published here, open a public issue in the project's GitHub repository. Do not include private data, credentials or recovery keys in a public issue.

Material changes to this policy will be published on this page with an updated date.
